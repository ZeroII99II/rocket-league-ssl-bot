# 🏆 SSL Learner - Complete SSL Learning System

A comprehensive system that learns SSL (Supersonic Legend) level Rocket League gameplay by watching pro videos, practicing in free play, and then going online to master skills.

## 🎯 What This System Does

1. **📹 Video Learning**: Watches SSL pro videos (jstn, GarettG, Squishy, etc.) to learn mechanics and strategies
2. **🎮 Free Play Practice**: Injects into Rocket League to practice learned mechanics in free play
3. **🌐 Online Practice**: Takes the bot online to practice in real matches
4. **🧠 Continuous Learning**: Keeps learning and improving while playing

## 🚀 Quick Start

### 1. Install Dependencies
```bash
pip install -r requirements_ssl.txt
```

### 2. Launch the System
```bash
python launch_ssl_learner.py
```

### 3. Choose Your Learning Mode
- **Quick Start**: 30min videos + 60min practice
- **Video Learning Only**: Learn from pro videos
- **Free Play Practice Only**: Practice in free play
- **Online Practice Only**: Practice in real matches
- **Full Pipeline**: Complete learning experience
- **Custom Configuration**: Set your own times

## 📋 System Components

### 1. SSL Video Learner (`ssl_video_learner.py`)
- Watches SSL pro videos from YouTube
- Analyzes video content for mechanics and strategies
- Learns from jstn, GarettG, Squishy, Kronovi, Lethamyr
- Extracts SSL-level knowledge

### 2. SSL Game Injector (`ssl_game_injector.py`)
- Injects into Rocket League process
- Controls the car in free play
- Practices learned mechanics
- Builds muscle memory

### 3. SSL Integrated Learner (`ssl_integrated_learner.py`)
- Combines video learning with game practice
- Manages the complete learning pipeline
- Coordinates between all components
- Tracks progress and learning

### 4. SSL Learner Launcher (`launch_ssl_learner.py`)
- Easy-to-use launcher interface
- Multiple learning modes
- Progress tracking
- Custom configuration
